## Welcome

# Welcome to Aitiarch

This is your notespace. Write and edit plain Markdown here; the notebook works with AI off.

Use the notes menu to create a note. Type `/` to choose a heading, list or other Markdown block.

Think and Ask send text only after review. AI replies are labeled AI. Your takeaway is yours to write; you can also Skip it.

Creating this folder sends nothing to a provider. Replace this note with your own writing when ready.

## Write in a note

Use the command palette to find actions or type `/` in the editor to insert headings, quotes, lists, tasks, note/tip/warning callouts, code fences, dividers, tables, links, images or footnotes. A decision begins with `Decision:` and can include `Why:` and `Rejected:` lines. Only you write the why, a takeaway or the reason something failed.

Note links connect your notes. Use `@` in chat to attach context to an AI request for review. Constellation shows connections, and Decisions brings recorded decisions together across notes.

## Read and review AI replies

Think and Ask show what will be sent before you send it. Their replies appear in margin threads. Use the Aitiarch AI panel for chat, the model chip to see the effective model choice, Setup to assign providers to roles, and Pipeline to see the steps, caps and editable settings.

Read-only replies render tables, strikethrough, checklists, lists, callouts and code. HTML and images are suppressed, links appear as text, and footnotes and internal note links have less support than in the note editor. AI replies can include Mermaid and dollar-delimited math as source text today. Rendered diagrams from Mermaid and rendered math in replies are planned.

When an explanation needs room, Explain aims for up to 1,200 prose words and 8,000 output tokens. Ordinary rich chat and thread replies aim for up to 600 words and 4,000 output tokens. These are writing guides. Any lower mode, provider or budget limit takes priority.
